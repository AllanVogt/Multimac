# ADR-001: Language and conventions

- **Status:** Accepted
- **Date:** 2026-10-05

## Context

The previous project (Absurd Market) uses English for code, commits and documentation. The audience of the site is Brazilian.

## Decision

Code, identifiers, commits and documentation are written in English. Site content (UI texts, product copy, SEO text) is pt-BR. Public route paths are in Portuguese (`/catalogo`, `/oficina`) because they are content that matters for SEO. Commits follow Conventional Commits.

## Consequences

Consistent with the portfolio goal and the previous project. Route names in the frontend code stay in English (component and file names) while the URLs users see are Portuguese.
